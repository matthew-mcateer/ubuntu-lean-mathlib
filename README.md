# ubuntu-lean-mathlib

A reusable `linux/amd64` container image with Ubuntu 24.04, Lean 4.35.0,
Mathlib, the Lean comparator tools, and Python verifier dependencies.

The image contains no benchmark tasks, tests, or solutions.

See [UPGRADING.md](UPGRADING.md) for the maintainer upgrade and validation
procedure.

```sh
docker pull ghcr.io/matthew-mcateer/ubuntu-lean-mathlib:lean4.35.0-mathlib4.35.0-comparator-e3dcf30
```
